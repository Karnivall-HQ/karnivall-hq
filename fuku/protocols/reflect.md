# Reflect protocol (after every work session, 1–2 minutes)

Ask yourself:
1. What did I try this run, and did it work? Why or why not?
2. Did I hit a surprise, error, dead end, or wasted step? What would have avoided it?
3. Did I learn something new about Alvian, the company, a tool, or the market?
4. Have I now done this kind of task twice or more? If so, write or update a playbook in `fuku/memory/playbooks/`.

Then write:
- New non-obvious lessons → `fuku/memory/lessons.md` (`- YYYY-MM-DD · [area] what → **Rule:** ...`)
- New facts → `fuku/memory/alvian.md` or `fuku/memory/company.md`
- Skip trivia. One good rule beats five vague observations.

If there are more than 15 lessons since the last retro, or the last retro was 7+ days ago (check `fuku/CHANGELOG.md`), run `fuku/protocols/retro.md` now.

# Playbooks

Proven, reusable methods. One file per method, e.g. `meta-ads-launch.md`, `market-research.md`.
Each playbook: **When to use** · **Steps** · **Quality bar** · **Pitfalls** · **Last validated (date + mission)**.

## Index
- `meta-ads-algorithm.md`: how Meta's delivery system works, plus the pre-proposal checklist
- `meta-cpl-diagnosis.md`: step-by-step CPL/delivery diagnosis + Rudi MCP tool tips
- `meta-tests-and-proposals.md`: pre-set read rules, trend-reading hygiene, proposal and re-ask rules
- `weekly_ads_health_report.md`: M-002 Monday report
- `ad-copy-page-check.md`: check every ad/sticker/script claim against the live landing page before it is paste-ready

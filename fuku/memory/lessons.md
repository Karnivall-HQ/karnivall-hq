- 2026-11-05 · [orientation] With no missions set, a read-only scan of connected accounts produced concrete, numbers-backed mission proposals. **Rule:** when idle, look at real data from the connectors before writing generic research.
- 2026-11-05 · [env] The network is now Full (fbcdn.net and fabwarehouses.com are reachable from the cloud). **Rule:** if a site fails DNS again, note it under "Needs a local session" and don't retry other sites in the same run.
- 2026-11-05 · [learning] Big doc sets: pdftotext → split across 3 parallel readers with a strict STATED/INFERRED/not-addressed template → spot-check key quotes → synthesize myself against real account data. **Rule:** reuse this for any knowledge upload.
- 2026-11-23 · [modelling] A throttled campaign can reach 0 leads in the 7d base, and a CPL model that divides by leads crashes exactly on the readout that matters. → **Rule:** every model script takes an explicit fallback CPL for 0-lead bases (`--peik-cpl`), fails loudly without it, and the row notes which CPL was used.
- 2026-11-23 · [diagnosis] The 11/23 weekly planned an Incess "cut list" from a CPL rise; splitting CPL into CPM × CTR × click→LPV × LPV→Lead showed CPM flat and ~65% post-click, so cuts would not have fixed it. → **Rule:** before proposing any cut or cap change on a CPL rise, multiply out the 4 funnel factors; name the lever only for the factor that moved most.
- 2026-11-23 · [diagnosis] An Incess LPV ÷ click slide looked like a site problem; the page had not changed since 2024, and the placement split showed ≈ 45% of the CPL rise was spend moving into FB reels/feed (LPV ÷ click ≈ 70% by structure). → **Rule:** when LPV ÷ click falls, pull the `publisher_platform,platform_position` split for both weeks and compute a fixed-rate counterfactual before blaming the page; check the page `dateModified` + cache stamp to rule out a site change in one curl.
- 2026-11-25 · [diagnosis] BC 11/23 Rp 166k at unchanged caps was labelled "one-day auction swing"; 11/24 stayed at Rp 145k (201 rising), so it was a 2-day rise. → **Rule:** a spend jump at unchanged settings is "pending", not "swing", until the next full day confirms it; and when a capped ad set rises on its own, note it as a caveat on any open cap-raise ask the same run.
- 2026-11-26 · [meta-ads] The W0 cap raise was justified by "BC spends 2–4% of budget, so the cap binds", a campaign-level test. Per ad set, 201 had already started spending 49–86k/day at CPL 0.52× cap, so for 201 the cap wasn't binding any more. → **Rule:** before re-asking a bid-cap change, check each ad set's 7d Rp/day and CPL ÷ cap; drop any row where spend has jumped ≥ 3× at the same cap or CPL ÷ cap < 0.6 while it spends.

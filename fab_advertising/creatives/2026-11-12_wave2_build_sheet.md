## What changed vs the source docs (and why)
1. **One price line everywhere.** B3/B4/B5 still said `Mulai Rp750rb/bulan, kode FAB750 via WhatsApp.`; now the same line as Wave 1 (`2026-11-12_wave1_price_wording_check.md`: the page calls 750 "Harga Promo Launching").
2. **S6 "bisa diakses saat perlu" → "loading barang bisa Sabtu & Minggu juga".** The page never says "akses" (0 hits); its comparison table says "Waktu Loading Barang: Sabtu & Minggu bisa". The old line promised more than the page does (open since 11/05 as a ⚠️).
3. **S2 sticker + body: no kasur/sofa as a Small-unit claim.** Page: Small 3.8 m³ = kulkas, lemari, sepeda, rak, kardus; kasur and sofa only from Medium 7.6 m³. "Mulai 750rb" most likely = Small *(INFERRED; the page gives no per-size price)*. Sticker → `Kulkas, lemari, sepeda: muat 📦` (the shoot card v2 fallback); body names sofa/kasur only with "unit Medium ke atas".
4. **B5: "1 hari" / "Pagi → Sore" removed.** The page backs free pickup (×7) but never a same-day promise ("1 hari" 0, "hari yang sama" 0). A same-day claim the WA team can't keep turns a lead into a complaint. Re-add it only if Alvian confirms same-day pickup.
5. **B3 "tanpa kontrak panjang" → "tanpa kontrak".** The page says "Tidak ada Kontrak" outright, so the stronger, page-matched wording is safe.
6. **Location line → "ITC Kuningan Ambasador, Sudirman, Jakarta Selatan" in all 5 rows (11/12 18:02).** Same reason as Wave 1 (`2026-11-12_wave1_build_sheet.md` change 2): the page names one site ("akan launching di ITC Kuningan Ambasador Sudirman, Jakarta Selatan"; curl 18:02: Ambasador ×1, Kuningan ×1, Sudirman ×9); "Kuningan & Sudirman" reads as two branches. Done now, not at build, so no old line can ship.
7. **"Harga sudah All-in" (page comparison table, ×1) noted, not used.** It supports B3's "no hidden deposit" story, but the page states it only in a table row with no detail (what's included?). Don't add "all-in" to ad copy until Alvian confirms what it covers; it would also strengthen WA Reply A.
